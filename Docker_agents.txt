[[Containers are lightweight, isolated execution environments (not VMs) used to run specific tasks.
Jenkins can run builds inside containers instead of long-running Jenkins slaves.
The container executes all pipeline steps; if the pipeline builds and pushes an image, that image is stored in a registry, and the build container is deleted.
Kubernetes runs Pods only when a deployment is updated to use that image.
To reduce idle compute cost, modern setups run Jenkins itself inside Kubernetes with ephemeral Pod agents, which is the industry standard today.]]
